Análise de regras de negócio (IA) — para tabelas complexas/virtuais

Este app não interpreta a query sozinho — ele monta o pedido, você roda numa IA (Copilot ou Genie Code) e traz a resposta de volta. Fluxo: 1) copie o prompt → 2) cole no Copilot/Genie Code → 3) cole a resposta aqui → o app usa isso nas Instructions e no prompt final, no lugar do TODO.

Instructions (texto)

Revise/edite aqui antes de gerar o prompt final — este texto entra dentro do prompt do Genie Code, abaixo. Tabelas ainda com [TODO] vão para o prompt como TODO mesmo — preencha a análise acima primeiro.

Example Queries candidatas

Uma por tabela complexa. Ajuste a descrição e confirme o SQL antes do prompt final.

Dicionário de valores por coluna

Valores literais encontrados em comparações (=, IN, LIKE) nas queries. Configure como Example Values/Value Dictionary direto na coluna (Configure → Sources → coluna) — reduz erro do Genie ao casar o que o usuário escreve com o valor real do dado. Não é algo que o Genie Code cria; é configuração manual por coluna.

Análise de medidas (IA) — traduz DAX para regra de negócio

O app não traduz DAX sozinho — ele monta o pedido, você roda numa IA (Copilot ou Genie Code) e traz a resposta de volta. Fluxo: 1) copie o prompt → 2) cole no Copilot/Genie Code → 3) cole a resposta aqui → substitui a expressão DAX crua nas Instructions.

Instructions — métricas (texto)

Ordenado por camada de dependência (base → derivadas). Medidas SEM resposta de IA colada ainda saem com a expressão DAX crua, marcada como não traduzida. Medidas marcadas como "Measure formal" não entram aqui — ficam só na Measure, sem duplicar.

Measures formais candidatas

Podem cruzar tabelas via Join já configurado — mas o Genie só aceita colunas reais, sem window function. Cada coluna precisa do nome real e completo da sua tabela na frente. Confirme/ajuste o SQL de cada uma.

Padrões marcados como "pergunta específica"

Estruturas de SQL não óbvias (Top N, Pareto, etc.) — cole o SQL de cada uma.

Prompt para o Genie Code

Um único prompt: Instructions, Measures e Example Queries desta etapa, tudo junto.
